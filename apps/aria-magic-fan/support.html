Support · Aria Magic Fan

Aria Magic Fan · 魔法风扇　·　Two editions: monitor and full control

Two editions. The Mac App Store edition is a read-only monitor. The website edition adds full fan control. This page explains the difference.

How to use it

  1. Open Aria Magic Fan. The icon appears in the menu bar.
  2. Click the icon to open the panel.
  3. Mac App Store edition: read the system load and thermal state. It does not change fan speed.
  4. Website edition: use the fan controls in the panel. Changes apply immediately; use Auto to return control to macOS.
  5. Quit from the menu when you are done.

Frequently asked

Why can’t the Mac App Store version control the fans?

Fan control needs direct access to the SMC, which App Store sandbox rules do not allow for this kind of utility. The App Store edition therefore uses public APIs only and stays read-only. The website edition is signed and notarized outside the App Store and includes full control.

Does the App Store edition change my settings?

No. It only reads system state. It does not change fan speed, power settings or login items.

Does it need an administrator password or a background helper?

No. There is no root helper and no privileged background service.

Does it collect data or use the network?

The Mac App Store edition is sandboxed without network access and collects no data. There is no account and no sign-in. See the privacy policy.

The menu bar icon does not appear

Quit the app and open it again. If it still does not appear, check that the app is in /Applications and tell us your macOS version (Apple menu ▸ About This Mac).

Where do I download the full-control edition?

From ariamagicvoice.com/apps. Pricing is shown on the website. It is a separate Developer ID build, not the App Store build.

Contact

Email magicvoice.team@outlook.com. Please include your macOS version, which edition you use (App Store or website), and what you expected to happen. We usually reply within two business days.

常见问题

为什么 Mac App Store 版不能控制风扇？

控制风扇需要直接访问 SMC，App Store 沙盒规则不允许这类工具这样做。因此 App Store 版只用公开 API，保持只读；官网版通过 Developer ID 签名与公证，提供完整控制。

App Store 版会改我的设置吗？

不会。它只读取系统状态，不改风扇转速、电源设置或登录项。

需要管理员密码或后台辅助进程吗？

不需要。没有 root 助手，也没有常驻的特权服务。

会收集数据或联网吗？

Mac App Store 版在沙盒内运行、没有网络权限、不收集数据；没有账号，也不需要登录。详见 隐私政策。

菜单栏图标不出现

先退出 App 再打开。如果仍不出现，请确认 App 在 /Applications，并告诉我们 macOS 版本（苹果菜单 ▸ 关于本机）。

全功能版在哪里下载？

在 ariamagicvoice.com/apps。价格以官网为准。它是独立的 Developer ID 版本，不是 App Store 版本。
