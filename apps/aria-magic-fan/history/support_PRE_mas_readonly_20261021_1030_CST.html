Support · Aria Magic Fan

Aria Magic Fan · Aria魔法散热风扇　·　Intuitive Mac fan speed and temperature control

Requirements

macOS 12.0 or later. Compatible with Apple Silicon (M1/M2/M3/M4/M5) and Intel Mac models with internal cooling fans.

How to use it

  1. Launch Aria Magic Fan. The current fan RPM and core temperature appear in the menu bar and status panel.
  2. Choose between Auto (system default), Custom (set fixed speeds or multi-tier thermal curve), and Full Speed (maximum cooling).
  3. On first activation of manual fan control, macOS will prompt for administrator permission once to install the local privileged helper tool.
  4. When quitting, the app can either restore system automatic control or keep your preferred speed, according to your preference in Settings.

Safety & Protection

  • Hardware Minimum Limit: The app never allows fan RPM below the system-defined minimum safety speed.
  • Emergency Overheat Protection: If CPU core temperature exceeds 92°C, the emergency cooling safety override engages automatically to protect your hardware.
  • Loss-of-Signal Failsafe: If the application terminates abnormally, the helper automatically restores macOS system fan control.

Frequently asked

Why does fan control require administrator privileges?

macOS requires elevated system authorization (privileged helper tool) to communicate with the Apple System Management Controller (SMC). The helper tool runs entirely on your local machine and never accesses personal files or the network.

How to completely uninstall the helper tool?

In Aria Magic Fan Settings ▸ General, click "Uninstall Helper Tool", or quit the app and run the following command in Terminal:

sudo rm -f /Library/PrivilegedHelperTools/com.harrywood.macfan.helper /Library/LaunchDaemons/com.harrywood.macfan.helper.plist

Do I need an account or an internet connection?

No. Aria Magic Fan operates 100% offline. All temperature readings, fan controls, and license verification run strictly on-device without telemetry or cloud tracking. See our Privacy Policy.

支持 · Aria魔法散热风扇

Aria Magic Fan · Aria魔法散热风扇　·　原生纯净的 Mac 风扇调速与温度监控工具

系统要求

macOS 12.0 或更高版本。支持 Apple Silicon（M1/M2/M3/M4/M5 系列）及配备风扇的 Intel Mac 机型。

使用方法

  1. 启动 Aria Magic Fan，菜单栏图标与状态弹窗将实时显示 CPU 核心温度与风扇当前转速。
  2. 自由切换三种模式：自动（交还 macOS 系统原生控制）、自定义（自定底速或阶梯温控曲线）、全速（拉满散热）。
  3. 首次启用硬件调速时，系统会弹出一次性管理员授权，用于安装本地安全控制助手（Privileged Helper）。
  4. 退出 App 时，可在设置中选择「交还系统自动控制」或「保持当前转速设定」。

安全与硬件保护

  • 硬件底线防护： 软件绝对不下发低于 Apple 官方硬件规定的最低安全转速。
  • 92°C 紧急降温： 当 CPU 核心温度达到或超过 92°C 时，自动触发最高转速散热保护，降温后平滑回落。
  • 异常断开兜底： 若主程序意外退出，本地守护助手将自动将风扇交还给 macOS 系统接管。

常见问题

为什么调节风扇需要管理员密码？

macOS 系统底层的 SMC 硬件写保护机制要求必须具有特权助手（Privileged Helper）才允许向风扇寄存器写入目标转速。助手程序纯本地运行，不含任何网络代码，不触碰任何用户隐私数据。

如何彻底卸载风扇控制助手？

在 App「设置 ▸ 通用」中点击「卸载风扇助手」，或退出软件后在「终端」中执行：

sudo rm -f /Library/PrivilegedHelperTools/com.harrywood.macfan.helper /Library/LaunchDaemons/com.harrywood.macfan.helper.plist

需要联网或注册账号吗？

完全不需要。Aria Magic Fan 遵循本地优先原则，所有传感器读取、转速调控与许可证校验均 100% 在本地离线完成，无任何网络请求与数据收集，详见隐私政策。
