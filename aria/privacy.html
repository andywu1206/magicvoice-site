Overview

Aria Magic Voice is a macOS AI input method for voice input, pinyin typing, local correction learning, and optional AI polish. Local processing and the User Experience Improvement Program are separate data paths.

The User Experience Improvement Program is managed separately in settings. It is limited to isolated correction pairs and quality signals, and excludes original recordings and complete source text.

Voice and Text Data

  • Free and the planned Pro tier process their local speech-recognition path on your Mac.
  • The User Experience Improvement Program is limited to de-identified isolated correction pairs and quality signals and is managed in settings.
  • The improvement program does not upload original recordings, complete chats, or account passwords.

Local Storage

Application configuration is stored locally at:

~/.config/magicvoice/

This directory may contain app settings and local correction-learning records. Local personal learning records remain on your Mac; the improvement program does not upload original recordings or complete source text.

Network Connections

Local Free and planned Pro input features can work offline. Network connections are limited to the path you choose:

  • Improvement program — Managed in settings; limited to de-identified isolated correction pairs and quality signals, and can be turned off.
  • Pro purchase candidates — Website licensing and Apple IAP are separate purchase paths. Neither path is available yet; each must present its own price, trial, restore, refund, and entitlement terms before launch.
  • Legacy license support — Earlier standalone purchases may still use device activation and recovery services.

Data Excluded From the Improvement Program

  • Original recordings
  • Complete chats or complete conversation histories
  • Account passwords, authentication secrets, or payment credentials
  • Raw paths, URLs, code, account identifiers, and other protected no-touch content

Payment Processing

Free is the no-charge tier. Pro is a one-time purchase (US$39.9). Website purchases will use a website license path; the Apple edition will use Apple IAP. Earlier standalone purchases processed by Paddle remain supported as legacy transactions.

This Website

ariamagicvoice.com is a purely static website hosted on GitHub Pages. This website does not use any analytics tools, trackers, or cookies. However, the website loads resources from the following external domains in order to render its pages:

  • Google Fonts (fonts.googleapis.com / fonts.gstatic.com) — for web typography. Google may log standard access data; see Google Fonts Privacy FAQ.
  • Phosphor Icons (unpkg.com) — for UI icons.
  • Tailwind CSS CDN (cdn.tailwindcss.com) — used by some support pages.

When your browser loads these resources, your IP address and basic request headers are sent to the respective CDN providers as part of standard HTTP requests. We do not control data handling by these providers.

Third-Party Services

The desktop application uses local processing for Free and the planned Pro input features. New Pro purchasing is not yet available: the website license path and Apple IAP path remain separate launch candidates. Legacy standalone purchases may continue to use existing activation and Paddle transaction support.

This website loads third-party font, icon, and CSS resources as described above. These services may receive standard HTTP request data, such as your IP address, when the page loads.

Data Retention and Deletion

  • Local app data — Settings, preferences, and local correction-learning records are stored on your Mac. You can remove local app data by uninstalling the application and removing its configuration directory at ~/.config/magicvoice/.
  • Improvement data — Turning off the program stops future uploads. Contact us to request deletion of improvement data associated with your support identifiers, where identifiable and technically available.
  • Activation data — Device identifiers stored on our server for license management can be removed by deactivating your license within the app, or by using the Device Recovery page.
  • Pro and legacy payment data — If Pro purchasing launches, the website payment provider will handle website transaction data and Apple will handle Apple IAP data under their respective policies. Paddle handles earlier standalone transactions under its privacy and data retention policy.
  • Data deletion requests — If you would like to request deletion of any data associated with your purchase or have questions about your data, please contact us at magicvoice.team@outlook.com.

Children's Privacy

The product is not designed to collect children's personal information. A parent or guardian should review the improvement-program settings before a child uses that network feature.

Changes to This Policy

If we make material changes to this Privacy Policy, we will update the content on this page and revise the "Last updated" date. We encourage you to review this page periodically.

概述

Aria Magic Voice 是一款 macOS AI 输入法，提供语音输入、拼音打字、本地纠错学习和 AI 自动润色。本地处理与加入体验改进计划是两条独立的数据路径。

加入体验改进计划在设置中单独管理，只处理隔离纠错对与质量信号，不上传原始录音或完整原文。

语音与文字数据

  • Free 和拟定 Pro 的本地语音识别路径在您的 Mac 上处理。
  • 加入体验改进计划只处理脱敏的隔离纠错对与质量信号，并在设置中管理。
  • 体验改进计划不上传原始录音、完整聊天或账号密码。

本地存储

应用配置存储在本地目录：

~/.config/magicvoice/

该目录可能包含应用设置和本地纠错学习记录。个人本地学习记录留在您的 Mac；体验改进计划不上传原始录音或完整原文。

网络连接

Free 和拟定 Pro 的本地输入能力可离线使用。网络连接严格区分为您选择的数据路径：

  • 体验改进计划 — 在设置中管理；只处理脱敏的隔离纠错对与质量信号，并可随时关闭。
  • Pro 购买候选 — 官网 License 与 Apple IAP 是两条独立购买路径，目前均未上线；正式上线前必须分别展示价格、试用、恢复购买、退款与权益条款。
  • 旧版授权支持 — 早期独立购买用户仍可能使用设备激活与恢复服务。

体验改进计划明确排除的数据

  • 原始录音
  • 完整聊天或完整会话历史
  • 账号密码、认证密钥或支付凭据
  • 原始路径、网址、代码、账号标识及其他 no-touch 保护内容

支付处理

Free 为永久免费版本。Pro 为一次性买断（¥268）。官网版本拟走 License 授权，Apple 版本拟走 Apple IAP；早期由 Paddle 处理的独立购买继续作为历史交易获得支持。

本网站

ariamagicvoice.com 是一个托管于 GitHub Pages 的纯静态网站。本网站不使用任何分析工具、追踪器或 Cookie。但网站在呈现页面时会从以下外部域名加载资源：

  • Google Fonts（fonts.googleapis.com / fonts.gstatic.com）— 用于网页排版。Google 可能记录标准访问数据，详见 Google Fonts 隐私常见问题。
  • Phosphor Icons（unpkg.com）— 用于 UI 图标。
  • Tailwind CSS CDN（cdn.tailwindcss.com）— 部分支持页面用于加载样式。

当您的浏览器加载这些资源时，您的 IP 地址和基本请求头信息会作为标准 HTTP 请求的一部分发送至相应 CDN 服务商。我们无法控制这些服务商的数据处理方式。

第三方服务

桌面应用 的 Free 和拟定 Pro 输入能力走本地处理。新版 Pro 尚未开放购买；官网 License 与 Apple IAP 是两条分离的候选路径。早期独立购买继续使用现有激活与 Paddle 历史交易支持。

本网站 加载上文所述的第三方字体、图标与 CSS 资源。这些服务可能在页面加载时接收标准 HTTP 请求数据，例如您的 IP 地址。

数据保留与删除

  • 本地应用数据 — 设置、偏好和本地纠错学习记录存储在您的 Mac。您可以通过卸载应用并移除配置目录 ~/.config/magicvoice/ 清除本地应用数据。
  • 体验改进数据 — 关闭计划后停止后续上传。对于能够通过支持标识关联且技术上可定位的数据，可联系我们提出删除请求。
  • 激活数据 — 存储在我们服务器上用于授权管理的设备标识符，可以通过在应用内停用授权码来删除，也可以使用 设备重置 页面来操作。
  • Pro 与历史支付数据 — 若 Pro 购买上线，官网支付服务商与 Apple 将分别处理各自渠道的交易数据；早期独立交易由 Paddle 按其隐私和数据保留政策处理。
  • 数据删除请求 — 如果您希望删除与购买相关的任何数据，或对您的数据有任何疑问，请通过 magicvoice.team@outlook.com 联系我们。
