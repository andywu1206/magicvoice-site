核心功能Core features

Aria Magic Voice 输入法的核心功能亮点Core highlights of the Aria Magic Voice input method

语音输入 + 拼音打字Voice input + pinyin typing
语音输入和拼音打字相互补充。切到 Aria 输入法后，可以单击左 Ctrl 说话，也可以正常打字。Voice input and pinyin typing complement each other. Switch to Aria, tap Left Ctrl to speak, or type normally.
语音聊天数据不上传Voice and chat data are not uploaded
原始录音和完整聊天内容只在本机处理，不上传。体验改进计划可在设置中管理，只处理隔离纠错对与质量信号。Original recordings and complete chat content are processed only on your Mac and are not uploaded. The User Experience Improvement Program can be managed in Settings and only processes isolated correction pairs and quality signals.
超级学习功能Super learning
当你把错字改成正确写法，Aria 会在本地学习这类修改。敏感数字、网址、路径、账号和代码不会盲目入库。When you correct text, Aria can learn that edit locally. Sensitive numbers, URLs, paths, accounts, and code are protected by safety rules.
AI 自动润色，口语表达更流畅AI polish for smoother wording
需要时开启自动润色，把口语表达变得更流畅；不开时就保持原始识别结果，适合记录、代码和敏感场景。Turn on polish when you want smoother phrasing, or keep it off for raw transcripts, code, and sensitive work.
