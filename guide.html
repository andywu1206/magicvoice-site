Follow these steps to install Aria, enable it as a macOS input method, and grant only the permissions required for voice input.

按照以下步骤安装 Aria、在 macOS 里启用输入法，并授予语音输入所需的权限。

Quick Start

  1. Install — Open the DMG and run the one-click installer. The input method edition installs into the macOS Input Methods location.
  2. Enable the input source — Open System Settings → Keyboard → Text Input, add or enable Aria Magic Voice, then switch to it from the menu bar.
  3. Start using — Tap Left Control once to start speaking. Tap Left Control again to finish and commit the text into the current field.

快速开始

  1. 安装 — 打开 DMG，运行一键安装器。输入法版会安装到 macOS 输入法目录。
  2. 启用输入源 — 打开系统设置 → 键盘 → 文本输入，添加或启用 Aria Magic Voice，再从菜单栏切换到它。
  3. 开始使用 — 单击 左 Control 开始说话，再次单击 左 Control 结束并自动上屏到当前输入框。

Basic Usage

  • Type normally — Use the Aria input source for regular keyboard input.
  • Start voice input — Tap Left Control once. A live draft appears underlined while you speak.
  • Finish voice input — Tap Left Control again. Final text commits to the focused field.
  • Optional AI polish — Turn it on when you want smoother spoken phrasing in writing.
  • Privacy — The User Experience Improvement Program can be managed in settings. It processes isolated correction pairs and quality signals, and does not upload original recordings or complete source text.

基本用法

  • 正常打字 — 使用 Aria 输入源进行常规键盘输入。
  • 开始语音 — 单击 左 Control，说话时实时草稿以下划线显示。
  • 结束语音 — 再次单击 左 Control，最终文本自动上屏到当前输入框。
  • AI 自动润色 — 可开可关，让口语表达更流畅。
  • 隐私边界 — 体验改进计划可在设置中管理；只处理隔离纠错对与质量信号，不上传原始录音或完整原文。

Settings

  • Voice trigger — The input method edition uses single-tap Left Control to start and finish voice input.
  • Interface language — Switch between Chinese and English interface.
  • Super learning — Learn local corrections while keeping sensitive numbers, URLs, paths, accounts, and code protected.
  • Voice and chat data are not uploaded — Original recordings and complete chat content stay on your Mac. The improvement program only processes isolated correction pairs and quality signals and can be managed in settings.

设置

  • 语音触发 — 输入法版使用单击左 Control 开始和结束语音输入。
  • 界面语言 — 支持中文/英文界面切换。
  • 超级学习功能 — 本地学习你的订正，同时保护数字、网址、路径、账号和代码。
  • 语音聊天数据不上传 — 原始录音和完整聊天内容只在本机处理，不上传；体验改进计划可在设置中管理，只处理隔离纠错对与质量信号。

Permissions

  • Microphone — Required for recording your voice. Must be granted.
  • Accessibility — Required to automatically insert text at the cursor position (simulates Cmd+V). Must be granted.

How to grant Accessibility permission:

  1. Open System Settings
  2. Go to Privacy & Security → Accessibility
  3. Click the + button and add MagicVoice

权限说明

  • 麦克风权限 — 用于录音,必须授予。
  • 辅助功能权限 — 用于将文字自动插入到光标位置(模拟 Cmd+V),必须授予。

如何授予辅助功能权限:

  1. 打开 System Settings(系统设置)
  2. 进入 Privacy & Security → Accessibility
  3. 点击 + 按钮,添加 MagicVoice

Troubleshooting

  • No sound / not recognizing — Check that Microphone permission is granted. Make sure the correct microphone is selected in your system Sound settings.
  • Text not inserting — Check that Accessibility permission is granted. Confirm MagicVoice is listed under System Settings → Privacy & Security → Accessibility.
  • Hotkey conflict — Try changing to a different hotkey combination in Settings.
  • Contact support — magicvoice.team@outlook.com

常见问题

  • 没有声音 / 不识别 — 检查麦克风权限是否已授予,确认在系统声音设置中选择了正确的麦克风。
  • 文字无法插入 — 检查辅助功能权限是否已授予,确认 MagicVoice 已添加到 System Settings → Privacy & Security → Accessibility 列表中。
  • 快捷键冲突 — 尝试在设置中更换其他热键组合。
